02 / PROJECT OVERVIEW

From rules to motion

03 / TECHNICAL SYSTEMS

How the scene works

The embedded module retains the original tree implementation while giving it a focused entry point and a lightweight presentation inside the portfolio.

Procedural branching

A tree model builds trunks, branches, and leaf nodes from depth, height, branch count, direction, and scale parameters. Generate a new tree to explore a fresh structure from the same rules.

Spatial wind field

A three-dimensional grid evolves over time, and trilinear interpolation supplies local wind forces. Branch and leaf motion can respond continuously rather than following a single global animation.

Stylized foliage

Camera-facing leaf planes use textured shader materials and distance-aware geometry selection. A small pooled particle system releases falling leaves to keep the scene alive without requiring the water simulation.

This portfolio module is built from the supplied FinalProject-Intro-To-Graphics-FA2025 source. The original tree classes remain in the included source directory; this page deliberately presents only the tree scene.
